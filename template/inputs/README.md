# Seed material

Drop anything here that should shape the video. The agent reads all of it before researching.

| Folder | Put here |
| --- | --- |
| `notes/` | Your own notes, outlines, other AI write-ups (.md, .txt) |
| `docs/` | PDFs, papers, slide decks, spec sheets |
| `images/` | Screenshots, photos, diagrams, logos you have rights to use |
| `media/` | Video and audio clips (recordings, voice memos, reference videos) |
| `links.md` | Web pages, repos, videos to read or watch |

Mark anything that must appear in the video, or must not, in `../brief.md`.
